## Todo List — список задач

![Todo List - скриншот приложения] (images/todo-list.png)

**Адаптивное веб-приложение для управления повседневными задачами.**

## О проекте

Todo List — учебный frontend-проект, разработанный для практики HTML, CSS и JavaScript. Приложение позволяет добавлять задачи, отмечать их выполненными, фильтровать список и сохранять данные между перезагрузками страницы.

Проект создан в рамках моего обучения frontend-разработке и демонстрирует работу с DOM, событиями, массивами и браузерным хранилищем.

## Функциональность

- Добавление новых задач
- Отметка задач как выполненных
- Удаление задач с подтверждением действия
- Фильтрация: все задачи, активные и выполненные
- Очистка выполненных задач
- Отображение количества оставшихся задач
- Сохранение задач в `localStorage`
- Восстановление данных после перезагрузки страницы
- Обработка некорректных сохранённых данных
- Адаптивная вёрстка для мобильных устройств и компьютеров
- Элементы доступности: ARIA-атрибуты и видимый фокус клавиатуры

## Используемые технологии

- **HTML5** — семантическая структура страницы
- **CSS3** — стилизация, адаптивная вёрстка и анимации
- **JavaScript (ES6+)** — логика приложения и работа с DOM
- **localStorage** — хранение задач в браузере

## Как запустить проект

1. Склонируйте репозиторий или скачайте проект.
2. Откройте папку проекта.
3. Откройте файл `index.html` в браузере.

Установка дополнительных зависимостей не требуется.

# Todo List — Task Manager

**A responsive web application for managing everyday tasks.**

## About the Project

Todo List is a frontend learning project built with HTML, CSS, and vanilla JavaScript. It allows users to add tasks, mark them as completed, filter the task list, and preserve data between page reloads.

The project demonstrates practical skills in DOM manipulation, event handling, array methods, and browser storage.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks with confirmation
- Filter tasks by all, active, and completed status
- Clear completed tasks
- Display the number of remaining tasks
- Persist tasks using `localStorage`
- Restore data after page reloads
- Handle invalid saved data
- Responsive layout for desktop and mobile devices
- Accessibility improvements with ARIA attributes and visible keyboard focus

## Technologies

- **HTML5** — semantic page structure
- **CSS3** — styling, responsive layout, and animations
- **JavaScript (ES6+)** — application logic and DOM manipulation
- **localStorage** — browser-based data persistence

## Getting Started

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies are required.
